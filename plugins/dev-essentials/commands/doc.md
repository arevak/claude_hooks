Target: {{target}} (function/class/module/API)
Format: {{format}} (inline/markdown/JSDoc/docstring)

Guidelines for Documentation:
1. **Code-level Documentation**:
   - Function/method purpose and behavior
   - Parameter descriptions with types
   - Return value descriptions
   - Exceptions/errors that may be raised
   - Usage examples
   - Complexity notes (time/space)

2. **Class Documentation**:
   - Class purpose and responsibilities
   - Constructor parameters
   - Public methods and properties
   - Usage examples
   - Design patterns used
   - Thread safety notes (if applicable)

3. **Module/Package Documentation**:
   - Module overview and purpose
   - Key components and their relationships
   - Public API surface
   - Installation and setup
   - Usage examples
   - Dependencies

4. **API Documentation**:
   - Endpoint descriptions
   - Request/response formats
   - Authentication requirements
   - Rate limiting
   - Error codes and messages
   - Example requests/responses

5. **Best Practices**:
   - Write for the intended audience
   - Use clear, concise language
   - Include code examples
   - Keep documentation up-to-date
   - Explain the "why", not just the "what"
   - Use consistent formatting

Generate complete, properly formatted documentation following language/framework conventions.
